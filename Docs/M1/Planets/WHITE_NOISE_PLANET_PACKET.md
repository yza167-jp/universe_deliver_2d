# Planet Packet — White Noise / 白噪星

## Canon status

- 冰原、冰洞、极光、电磁暴雪、较强重力、记忆档案文明与特高压电屏蔽罩：PROVISIONAL 框架已批准用于 M1。
- 角色显示名、物种、货物显示名和聚落名：候选制，未锁定。

## One-sentence identity

一颗被电磁暴雪覆盖的冰封星球，其地下文明将记忆保存视为公共基础设施，却正因“谁有权决定永久保存什么”而分裂。

## Narrative role

- 第二颗完整星球，验证 M0 架构可扩展。
- 第一次使用剧情必需模块。
- 将中继网与跨世代档案联系起来。
- 引入关系、许可、图鉴和正式支线循环。

## Natural environment

- 相对重力工作范围：1.2–1.35。
- 表面：冰原、裂谷、冰洞入口、极光。
- 天气：高压电磁暴雪、低能见度、静电放电。
- 地下：较稳定的档案层、透明/半透明材料与冰中光带。
- 光照：外部冷白/深蓝，地下使用暖白档案光和极光反射。

## Civilization

- 生活在冰层下，以保存、校验和继承记忆为核心。
- 记忆既是私人经验，也是历史、技术和公共责任。
- 档案维护者承担“长期保留成本”，不把无限保存视为天然善。
- 公司试图把索引和访问权包装为跨文明档案服务。

候选文明/聚落称呼：

1. **推荐工作候选：** 静层档案区 / Still-Layer Archives
2. 冰下记忆库 / Under-Ice Memory Vaults
3. 白噪共存层 / White Noise Continuity Layer

## Local conflict

一套关键档案索引损坏。公司要求恢复并接入商业服务，当地不同角色则争论：索引是否会暴露私人记忆、谁有权授权、删除是否也可能是一种保护。

## Flight identity

阶段建议：

```text
远处冰星与极光
→ 高压碎冰航道
→ 较强重力接近
→ 电磁暴雪层
→ 低能见度冰原
→ 冰裂谷/冰洞入口
→ 地下档案航道
→ 着陆/对接档案平台
```

独特机制：

- 较强重力要求更早拉起。
- 电磁干扰影响导航稳定、部分 HUD 和提示，不直接反转控制。
- 屏蔽罩降低干扰持续时间/强度与资源风险。
- 路线提示与高对比模式在暴雪中必须有效。

T-111 实现基线：

- 只有已安装的 `capability_high_voltage_shielding` 才参与危险计算；仅拥有模块
  不能替代出发前安装检查。
- 高压资源伤害暂乘 `0.60`，电磁干扰暂乘 `0.45`，数值集中在模块 Resource，
  白噪路线不得再复制硬编码。
- 高压伤害缩放后继续进入普通护盾优先入口；模块不会创建独立护盾条或完全免疫。

## Arrival scene

- 冰下档案区 1–2 屏。
- 主要 NPC、索引终端、可选记忆持有人。
- 玩家选择最小公开索引、保持封存或交给当地共同保管。
- 所有选择推进主线；影响关系、许可、图鉴和后续对白。

## Side order

`side_white_noise_returned_memory`：被退回的记忆盒。

- 将私人记忆盒归还持有人/代理。
- 选择公开索引、保持私密或只归还副本。
- 使用较短路线或主线路线分支。

## Revisit seed

- 档案是否对外开放。
- 某段被隐藏的中继历史是否重新出现。
- 记忆持有人后续状态。

## Relay clue

当地档案显示某些索引地址使用了远早于公司标准的协议。记录不说明创造者，只证明网络至少曾服务于跨世代信息定位。

## Art package

- 冰蓝、灰白、深海蓝、极光绿/粉。
- 冰裂缝、透明档案层、埋在冰中的光带。
- 电磁噪声使用图形与节奏，不依赖不可读全屏雪花。
- 核心 NPC、货物、屏蔽罩和纪念品图标。

## Audio package

- 冰风、低频结构声、静电、档案机械。
- 安全/暴雪/地下三层环境。
- 短主题动机：冷静、重复、像被校验的记忆片段。
