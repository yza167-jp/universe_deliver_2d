# 00 — Game Vision / 游戏愿景

## 一句话概念

《我在宇宙送快递》是一款重剧情的 2D 复古科幻公路游戏：玩家与外星水豚伙伴老皮经营银河边境快递站，在宁静的星际旅行与紧张、完全可操控的星球进入之间往返，通过一份份与文明和人物命运相关的订单，逐步发现银河物流网络背后的秘密。

## 核心幻想

玩家不是拯救宇宙的舰队司令，也不是无限刷单的自动驾驶员，而是一个在庞大宇宙里显得很小、却真实参与他人生活的快递员。

玩家应当感受到：

- “我真的从遥远太空亲手飞进了一颗星球。”
- “这颗星球不是皮肤，它有自己的自然规律、建筑、历史和居民。”
- “我送的不是随机箱子，而是一件会影响某个人或某个群体的东西。”
- “老皮一直和我在一起，我们拥有一个逐渐变化的家。”
- “公司对一切都有荒谬的制度，但宇宙里的人仍然认真生活。”
- “我可以选择更谨慎、更和平，也可以给飞船加装武器，但游戏会记住我的方式。”

## 五个设计支柱

### 1. 星球进入是一段可操控的仪式

关卡不是从地表开始。玩家从目标星系外缘进入，看到星球逐渐变大，穿过陨石和近轨道空间，进入大气层，承受重力、阻力、雷暴和视野变化，最后抵达地表。

这段过程必须：

- 全程由玩家控制，而不是自动演出。
- 使用压缩的电影化尺度，不模拟真实天文距离。
- 允许快速俯冲，也允许缓慢滑翔观景。
- 通过背景、音频、操控参数和危险层次逐步变化。
- 每颗星球都形成不同的“进入记忆”。

### 2. 宇宙旅行是宁静的陪伴空间

快递站和驾驶舱不是功能菜单的包装，而是情绪空间。玩家可以听环境音、看窗外、与老皮闲聊、查看货物或收音机，让高速飞行前后有呼吸和余韵。

宁静不等于空白。每次旅行应至少承担一种作用：

- 加深角色关系。
- 提供世界观碎片。
- 让玩家为目的地形成期待。
- 回应上一单的结果。
- 通过静默、风景或声音塑造孤独感。

### 3. 每颗星球都是自然与文明共同构成的地点

星球差异不能只来自重力和颜色。至少要同时体现：

- 自然：地形、气候、重力、大气、生态。
- 人文：建筑、交通、制度、劳动、信仰、技术、审美。
- 冲突：当地人物为什么需要这件货，谁希望它送到或送不到。
- 飞行：当地环境和文明如何改变玩家的路线与策略。

### 4. 货物是剧情物件，玩法限制有世界内原因

货物不会从“易碎、重型、危险”三个抽象词条随机组合。重要货物有发送者、收件人、历史、隐藏信息和具体影响。

玩法限制必须能回答“为什么”：

- 为什么不能 Boost？
- 为什么碰撞会造成严重后果？
- 为什么会吸引生物或扫描？
- 为什么必须装某个模块？
- 为什么公司和收件人对它的描述不同？

### 5. 故事基本线性，但玩家的方式会被记住

主线星球顺序基本固定，以保证叙事节奏和制作规模。玩家仍然拥有局部表达：

- 接受或拒绝支线。
- 选择和平/武装配置。
- 俯冲或滑翔。
- 保护货物或追求速度。
- 在局部人物冲突中做选择。
- 是否回访、收集和追查秘密。

这些选择优先改变关系、台词、当地状态、支线入口和结局权重，不制造四套完全不同的主线关卡。

## 情绪配方

整体不是持续 Cozy，也不是持续危险。目标节奏为：

| 场景 | 主要情绪 | 次要情绪 |
|---|---|---|
| 快递站大厅 | 温暖、日常、安全 | 荒诞公司制度、轻微孤独 |
| 星际驾驶舱 | 宁静、辽阔、陪伴 | 神秘、怀旧 |
| 星系接近 | 壮丽、期待 | 不安 |
| 大气层与地表飞行 | 紧张、专注、速度 | 景观欣赏 |
| 目的地剧情 | 人物亲近、文化差异 | 冲突、黑色幽默 |
| 返航与结算 | 余韵、成长 | 公司评价的荒谬感 |

## 主线与长期动力

### 主线完成前

主要动力：

- 解锁下一颗主线星球。
- 认识新角色并回访旧角色。
- 获得主线所需飞船模块和通行许可。
- 改善唯一飞船和快递站。
- 逐步理解“无法取消的订单”和古老物流网络。

支线的作用：

- 提供自由探索与额外角色故事。
- 提供升级资源和替代推进路径。
- 为主线门槛提供多种可控解法。
- 展示主线未覆盖的星球侧面。

支线不应成为随机刷钱劳动。

### 主线完成后

主要动力：

- 完成货物、纪念品、人物、星球和异常信号图鉴。
- 回访变化后的星球。
- 解开更深层宇宙秘密。
- 扩建快递站和进一步改装飞船。
- 达到约 95% 图鉴条件后开启隐藏结局。

## 目标玩家

适合：

- 重视世界观、角色关系和旅途感的单人玩家。
- 喜欢载具操作，但不要求硬核模拟的玩家。
- 喜欢像素美术、复古未来主义、氛围电子音乐的玩家。
- 愿意在故事段与操作段之间交替的玩家。
- 喜欢探索和收集，但不喜欢重复刷取的玩家。

不以以下玩家为主要目标：

- 只想要高密度战斗和装备刷取。
- 只接受完全开放沙盒、不接受线性主线。
- 期待真实轨道力学或严格飞行模拟。

## 体验成功标准

一次主线订单结束后，玩家至少应产生两种愿望：

1. 想知道老皮或某个星球角色接下来会怎样。
2. 想亲自进入下一颗具有不同自然/文明景观的星球。

如果玩家只在意报酬数字，说明叙事与地点塑造不足；如果玩家只想跳过飞行，说明星球进入的操作与景观不足；如果玩家只想飞行、不关心收件人，说明货物与剧情连接不足。

## 明确非目标

- 无缝 3D 宇宙。
- 可自由降落任意星球表面的开放世界。
- Roguelike、随机地图或随机词条驱动。
- 重战斗或地表枪战。
- 复杂飞船模拟、维修经济和死亡螺旋。
- 把精准停靠作为全游戏的核心难度。
- 大量程序生成 NPC 与通用对话。
- 每个选择都创建完全不同的主线关卡。
- 从第一天追求最终美术和全部配音。

## 参考方向（借鉴维度，不是复制清单）

| 参考 | 希望借鉴 | 不借鉴 |
|---|---|---|
| `Outer Wilds` | 以好奇心推动探索、地点与秘密互相解释 | 时间循环结构、完全开放顺序 |
| `Cloudpunk` | 快递职业作为认识城市人物的叙事入口 | 3D 开放城市规模 |
| `FAR: Lone Sails` | 载具、旅途、环境与孤独感的统一 | 单一连续载具内部玩法 |
| `Sable` | 风景、孤独旅行和不同聚落气质 | 大型开放世界 |
| `Citizen Sleeper` | 小人物、制度压力、温暖关系 | 纯文本/骰点为核心 |
| `Luftrausers` | 简洁但有惯性的 2D 飞行可读性 | 战斗密度和街机得分导向 |
| `A Short Hike` | 小规模空间中的角色温度与轻松探索 | 纯轻喜剧基调 |
| 复古科幻动画与唱片封面 | 高饱和局部色、巨大天体、模拟仪表感 | 牺牲 UI 可读性的滤镜堆叠 |

## 愿景保护问题

新增任何大系统前回答：

1. 它是否让星球、角色或旅途更有意义？
2. 它是否强化可操控的星球进入？
3. 它是否会制造重复劳动或内容指数膨胀？
4. 能否先用更小、更可逆的方式验证？
5. 它是否会让 M0/M1 延迟，却没有改善核心体验？

若第 1、2 项都是否，且第 3、5 项为是，默认不做。
