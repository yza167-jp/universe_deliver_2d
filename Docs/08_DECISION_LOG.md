记录会影响产品、范围或架构的决定。实现历史由 Git 负责。

## 状态

- `Locked`：用户已确认，变更需明确新决定。
- `Working`：当前默认方案，可通过试玩调整。
- `Open`：未决定，不阻塞当前任务。
- `Superseded`：已被后续决定替代。

## 变更规则

- 新用户决定优先于本表旧决定。
- 变更 Locked 项时新增一行，旧项标记 `Superseded`，不要删除历史。
- Working 项可由人工试玩调整，但要记录日期、原因和影响任务。
- Open 项不得被 Codex 根据个人偏好静默锁定。
