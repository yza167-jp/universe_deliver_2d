# 01 — Narrative Bible / 叙事圣经

本文件区分“已锁定正史”“暂定骨架”和“开放问题”。Codex 不得把暂定内容擅自升级为正史。

## Canon Status

- **LOCKED**：用户已确认。实现和文本不能自行改写。
- **PROVISIONAL**：当前可用于 M1 的工作设定，后续可重写。
- **OPEN**：尚未决定，开发时只保留接口、稳定 ID 或最小占位。

M1 的星球工作包位于 `Docs/M1/`。工作包中的暂名、物种、货物、制度细节和中继网内容默认仍为 `PROVISIONAL`。

## 1. 已锁定设定（LOCKED）

### 标题

- 中文：**《我在宇宙送快递》**
- 英文工作名：**Universe Deliver**

### 玩家

- 玩家是来自地球的人类。
- 玩家受雇于“银河外卖公司”，被分配到一个边境快递站点。
- 玩家不是无人格摄像机：可以通过少量对话选项表达态度，但不进行大段自说自话。
- 玩家默认无配音。
- 玩家可输入名字；当前使用固定或轻量可选的制服像素形象。

### 老皮

- 老皮是一名外星人，物种外观是一只水豚。
- 他会直立行走、会说话、具有人格与职业身份。
- 不同文明通过普及的同声传译器交流，因此所有角色可以自然对话。
- 老皮是玩家固定伙伴，从游戏开始就出现。
- 老皮在前期承担教程，但他的功能远不止教程。
- 老皮会出现在快递站与飞船副驾驶位置。
- 名字固定为“老皮”，不由玩家命名。

### 游戏结构

- 有明确主线和结局的单人游戏。
- 主线星球按大致固定顺序解锁。
- 可以存在支线星球、支线订单与回访内容。
- 主线尽量不产生大规模分叉。
- 主线结束后允许继续游玩和收集。
- 约 95% 图鉴完成度可以触发隐藏结局。

### 战斗边界

- 玩家可以形成和平快递员或武装运输者倾向。
- M0/M1 只实现飞船激光炮轰击陨石和明确环境目标。
- 星球地表角色剧情没有战斗环节。
- 武装选择可以影响 NPC 态度、检查、通行、路线便利和对白。
- 和平路线不能只是“少装一个有趣功能”，应得到信任、便利或独特内容。

### 基地与飞船

- 快递站大厅是 2D 俯视可步行空间。
- 初始主要员工只有玩家和老皮。
- 玩家长期使用一艘飞船，而不是频繁换船。
- 飞船通过数值升级、模块升级与剧情功能升级成长。
- 快递站可以升级并产生可见场景变化。
- 中后期站点可能迁移、受损或被迫离开，但尚未锁定。

### 交付与人物

- 目的地主要采用“场景式对话 + 小型可步行区域”。
- 普通订单可以只使用场景式对话。
- 重要主线地点可开放 1–2 屏的小区域与 NPC/物件互动。
- 交付方式随剧情变化，包括着陆、低空投放、检查门和对接等。
- M1 正式实现着陆与低空投放；其他方式继续保留为未来类型。

## 2. 暂定世界骨架（PROVISIONAL）

### 银河外卖公司

工作名：**银河外卖公司**。英文法人名仍未锁定，当前 UI 可以继续使用 `Galactic Delivery Corporation` 作为占位。

公司不是简单的纯恶反派。目标是“荒谬、庞大、官僚、逐利，但内部也有普通人和必要服务”。

公司特征：

- 将跨文明配送包装成生活服务与文明连接工程。
- 对所有风险拥有冗长免责条款。
- 管理层会在货物受损时来电，语气礼貌但冷酷。
- 依赖一套远早于公司成立的物流基础设施，却在宣传中暗示全部由公司发明。
- 对边境站点采取成本中心思维，因此玩家站点面临关闭或合并压力。
- 公司并非所有事件的唯一幕后黑手；某些部门、员工和客户可能真诚帮助玩家。

写作禁忌：

- 不把公司写成每句台词都在大喊“我们很邪恶”。
- 黑色幽默必须先传递有效信息。
- 不让公司制度压倒每颗星球自身的自然、文化与冲突。
- 不让每份订单都重复“公司撒谎”同一种反转。

### 同声传译器

- 常见基础设施，让不同物种交流无需反复解释。
- 翻译通常自然，但可在少量情节中出现文化语义偏差。
- 不把“语言不通”作为每颗星球的重复障碍。
- 传译器可能与古老物流网络共享协议，这是潜在伏笔，不是 M1 必须确认的事实。

### 古老物流网络

暂定名称：**中继网 / Relay Lattice**。

当前故事骨架：

> 玩家被派到一座即将被关闭的边境快递站。公司系统逐渐生成无法正常追溯来源、权限或目的地的订单。为了获得航行权限和必要模块，玩家与老皮依次访问不同星球，完成当地订单并重新接触一批被公司当作普通物流节点使用的古老设施。玩家逐渐发现，这套网络不是公司建造的，而老皮或水豚物种似乎能感知其中的某种信号。

M1 可以明确：

- 网络明显早于银河外卖公司存在。
- 不同星球保存了彼此不完整、互相印证的网络记录。
- 公司正在使用网络，但其真实知情程度仍不确定。

M1 不得锁定：

- 网络由谁建造。
- 网络真正运输的是物质、信息、生命、记忆还是其他东西。
- 老皮与网络是物种关联、个人经历还是巧合。
- “不存在的收件地址”是否位于银河之外。
- 公司高层知情程度。

### 结局方向

普通结局暂定围绕：

- 将网络控制权交给公司。
- 让各星球共同管理或公开网络。
- 关闭或破坏关键部分以阻止滥用。

隐藏结局暂定：在图鉴约 95% 后发现网络连接范围远超当前银河，并解锁新的最终选择或目的地。

M1 只建立结尾变量和悬念，不实现完整结局系统。

## 3. M0 故事结果（PROVISIONAL，已实现基线）

### 序章：边境站点

玩家在长期缺员的站点开始工作。老皮熟悉设施和公司流程，用松弛而实际的方式带玩家完成入职。

公司通知：

- 站点处于“运营效能观察期”。
- 若未达成最低配送指标，将被自动合并。
- 合并说明中对老皮的员工安置条款含糊不清。

### 第一份货物

工作名：**深层冷却泵核心**。

公司描述：

> 用于赤砂星 7 号采掘区生产维护的标准冷却设备。

客户历史：

- 收件账户近期连续下过多份冷却与净水设备订单。
- 若干订单被公司以“工业配额异常”取消。
- 实际收件地点并非公司正式仓库，而靠近工人居住区。

玩法关系：

- 货物对强烈碰撞敏感，完整度影响设备能否立刻启用。
- 货物不禁止所有 Boost，但雷暴和高速碰撞会提高风险。
- 公司设施能够识别订单和货物信号；赤砂星最终规则是**低空管制雷达惩罚过低飞行，高位安全**，而不是贴地躲雷达。
- 玩家需要在设施区保持最低安全高度，随后进入无雷达着陆准备走廊，从高处完成最终下降。

### 赤砂星抵达

玩家可以：

- 快速俯冲：抵达更快、下降风险更高，角色会回应驾驶方式。
- 缓慢滑翔：触发更多景观或广播信息。
- 常规进入：中性反馈。

玩家穿过陨石、连续入大气、雷暴、低空管制设施与高位着陆进场，最终抵达居民维修场。

### 第一位星球 NPC

工作名：**伊娅 / Iya**。

- 赤砂星当地技术员，负责维护聚居地冷却和净水系统。
- 不把自己描述为英雄，只想让设备运行到下一个风季。
- 对银河外卖公司既依赖又不信任。
- 知道订单记录被改写，但不知道是谁改写。
- 给予玩家旧中继节点碎片/铭牌作为纪念物与线索。

### M0 结尾

- 玩家返回站点，获得信用点和一次站点变化。
- 老皮对中继铭牌产生短暂异常反应，但没有解释。
- 导航系统显示新的远方目的地，为 M1 留下入口。

## 4. M1 主线骨架（PROVISIONAL）

推荐顺序：

```text
赤砂星序章
→ 白噪星
→ 赤砂星回访与成长
→ 穹林星
→ 跨星球支线与许可收束
→ 群潮星
→ M1 尾声
```

### 4.1 白噪星 / White Noise

**自然：** 冰原、冰洞、极光、电磁暴雪、较强重力。

**文明：** 居住于冰层下、以保存记忆与档案为核心的文明。

**冲突：** 哪些记忆应被保存、删除或公开；公司将档案服务商品化。

**飞行：** 低能见度、较强重力、电磁干扰和冰洞路线；需要特高压电屏蔽罩。

**故事功能：**

- 第一颗新增垂直切片。
- 第一次要求玩家通过确定路径获得主线模块。
- 揭示中继网的历史记录，但不解释创造者和用途。

**回访种子：** 玩家局部选择影响一部分档案公开、封存或转移。

工作包：`Docs/M1/04_WHITE_NOISE_PLANET_PACKET.md`。

### 4.2 赤砂星回访

**作用：** 证明配送改变地点，而不是完成后永久丢弃内容。

工作方向：

- 冷却与净水设备已投入运行。
- 伊娅和维修场出现可见变化。
- 新增一份成本受控支线。
- 首次正式使用低空投放或加急机制中的至少一项。
- 图鉴、纪念品、快递站和飞船成长产生第一轮 M1 反馈。

具体支线与投放位置仍为 OPEN，由 T-122/T-123 决定。

### 4.3 穹林星 / Canopy World

**自然：** 巨树、树冠城市、藤蔓、孢子云、飞行生物。

**文明：** 强调生态互依、对外来武器高度警惕的树冠文明。

**冲突：** 外部运输需求与生态边界；某件货物会吸引当地生物。

**飞行：** 树洞、树冠通道和移动生态障碍；飞行生物不是可射击敌人。

**故事功能：** 明确反馈玩家是否安装武器，推进和平/武装身份差异。

**回访种子：** 某条迁徙路线或树冠区域因玩家交付发生变化。

### 4.4 群潮星 / Tidal Archipelago

**自然：** 海洋、岛屿群、强风、雷暴、巨大潮汐。

**文明：** 多个相互竞争的岛屿城邦与天气塔网络。

**冲突：** 谁控制天气和航路；公共安全与城邦权力。

**飞行：** 横风、海面飞行、移动平台与天气塔。

**故事功能：** M1 高潮；多个早期角色、许可、模块或线索交汇；首次明确证明中继网不是公司建造。

**回访种子：** 天气塔状态改变后开放新的岛屿或深海信号。

### 4.5 M1 尾声

- 玩家返回快递站。
- 公司对中继设施的解释与实际证据发生明显矛盾。
- 老皮对新的信号或坐标产生更明确反应，但仍不解释全部真相。
- Demo 提供悬念结尾，并允许玩家继续查看支线、图鉴和回访内容。
- 不在 M1 展示完整结局或银河外区域。

## 5. 角色写作规则

### 老皮的声音

老皮应当：

- 经验丰富，但不是无所不知。
- 说话直接、松弛，偶尔把危险当作行业常识。
- 能在荒谬公司流程中找到实际可行的办法。
- 会关心玩家，但不总用煽情方式表达。
- 对吃、休息、温度和水有水豚式偏好，但不能只靠动物梗存在。
- 在教程中解释“做什么”，很少解释具体按键；按键由 UI 提示。
- 偶尔沉默，让环境和玩家行动说话。
- 随 M1 对中继网信号表现出逐渐增强但仍可否认的反应。

避免：

- 每句都抖包袱。
- 把他写成幼儿化宠物。
- 让他替玩家完成所有推理。
- 在 M1 过早明确他与终极秘密的关系。

### 玩家对话

玩家选项通常表达态度，而非彻底改变主线：

- 真诚/关心。
- 职业/务实。
- 怀疑/讽刺。

常规为 2–3 个选项。选择后至少有一行明确回应；避免大量只有措辞不同、无任何反馈的假选择。

### 星球 NPC

每个主要 NPC 至少具备：

- 一个当前具体目标。
- 一个与当地文明有关的日常细节。
- 一个对公司或配送网络的独立立场。
- 一处与玩家初始印象不完全一致的特征。
- 一个回访时可变化的状态。

NPC 不应只承担百科说明、模块发放或奖励功能。

### 公司管理层

公司警告的写法：

1. 先给出具体可操作信息。
2. 再用制度化措辞制造黑色幽默。
3. 不连续打断玩家。
4. 避免在高难操作时播放长对白。

示例语气，不是最终文本：

> 检测到货物完整度下降。依据《跨星系易损件友善关怀准则》，本次事故将被记录为您主动参与的职业成长活动。

## 6. 货物叙事模板

每件主线货物至少定义：

```text
cargo_id
name_key
sender_character_id
recipient_character_id
origin_planet_id
destination_planet_id
company_description_key
story_description_key
hidden_description_key (optional)
customer_history_keys[]
flight_restrictions
delivery_method
required_modules[]
recommended_modules[]
failure_consequences
associated_story_flags[]
relationship_effects[]
permit_or_codex_rewards[]
revisit_consequences[]
```

公司描述、实际用途和隐藏信息可以不一致，但差异必须服务人物和地点，不应每单都复制“公司撒谎”的同一种结构。

## 7. 分支与回访规则

- 主线星球顺序固定或只有极少局部交换。
- 选择主要改变：NPC 关系、后续对白、当地视觉状态、支线、许可、路线便利和结尾变量。
- M1 至少实现一次明显回访，当前计划为赤砂星。
- 重要星球长期计划初识与回访两次访问。
- 回访必须改变至少两项：视觉、NPC 状态、对话、订单、图鉴或路线条件。
- M1 不实现完整多结局，只建立稳定的结尾变量。
- 隐藏结局条件不要求绝对 100%，长期目标约 95%。

## 8. M1 内容 Packet 规则

新增星球在进入高成本实现前，必须完成：

- Planet Packet。
- Main Order Packet。
- Character Packet。
- Route Beat Sheet。
- Art/Audio Package。
- Scope Review。

Packet 中所有未被用户确认的姓名、物种、制度、货物和历史细节均保持 `PROVISIONAL`。

## 9. 开放问题（OPEN）

这些问题不阻塞当前 M1 基础任务：

- 玩家姓名与外貌选项的最终范围。
- 银河外卖公司的正式英文名、品牌色和组织结构。
- 老皮的具体年龄、过去和加入公司的原因。
- 老皮是否知道中继网真相，知道多少。
- 水豚物种的母星与文化。
- 快递站中后期是否迁移、受损或被迫离开。
- 古老物流网络的创造者和真实用途。
- 普通结局的确切数量与内容。
- 隐藏结局是否进入银河外区域。
- 伊娅的最终姓名、物种和文化语言细节。
- 白噪星 NPC 的最终姓名、物种和记忆媒介。
- 特高压电屏蔽罩的最终获取形式。
- 赤砂回访中的低空投放属于主线还是支线。
- 群潮星尾声展示的异常坐标/信号具体是什么。

实现涉及这些内容时，使用可替换 ID、`PROVISIONAL` 文本或明确待确认方案，不得自行永久锁定。
