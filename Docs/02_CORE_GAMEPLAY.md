# 02 — Core Gameplay / 核心玩法

## 1. 游戏不是“接单刷关”，而是线性旅程

核心结构为有主线顺序的长流程单人游戏。玩家会在固定快递站与多颗星球之间往返，并通过支线探索获得升级资源、人物关系和额外秘密。

一份主线订单不是独立 Roguelike 局，而是章节中的一个叙事行动。玩家可以随时保存、停留在大厅、回看资料或进行支线，不要求“玩一单就退出”。

M0 先在结算页与快递站等稳定节点自动保存。主菜单的“继续游戏”恢复剧情、订单、
信用点、飞船配置和站点变化后回到快递站，不尝试恢复飞行中的场景节点；完整的
任意地点手动存档仍不属于 M0。

## 2. 五层玩法

### 2.1 快递站大厅

**视角：** 2D 俯视。

**作用：** 家、叙事枢纽、订单管理、升级反馈。

主要动作：

- 行走和查看站内物件。
- 与老皮及访客交谈。
- 使用订单终端。
- 查看客户历史与星球资料。
- 在工作台配置飞船模块。
- 查看纪念品墙、货物与图鉴。
- 触发站点升级或剧情变化。

大厅初始范围小，功能区清楚。升级优先产生可见变化，而不是只增加菜单数字。

可能的中后期剧情变化包括迁移、受损或被迫离开，但 M0/M1 不在未确认前实现。

### 2.2 第一人称驾驶舱旅行

**视角：** 固定 2D 第一人称。

**作用：** 目的地确认、旅途情绪、老皮关系、世界观过渡。

玩家不在巡航时自由驾驶方向，而是通过可交互热点参与：

- 导航屏：设定当前订单允许的目的地。
- 窗外：观察天体、异常信号和接近过程。
- 老皮座位：聊天、触发剧情。
- 公司终端：接听通知、查看风险提示。
- 收音机：听当地广播、音乐或背景新闻。
- 货舱指示器：检查货物状态与说明。

首次主线旅行包含必触发内容；已看过的普通旅行段可加速或跳过。

### 2.3 星球进入与横版飞行

**视角：** 横向侧视。

**作用：** 仪式感、操作挑战、景观展示、订单限制兑现。

关卡从目标星系外缘或接近航道开始，按电影化压缩尺度经过：

```text
空间接近 → 陨石/航道 → 近轨道 → 大气边缘
→ 中层大气危险 → 低层沙漠、设施与低空管制雷达
→ 无雷达着陆准备走廊 → 高位最终着陆进场
```

路线总体从左向右，但玩家可以：

- 刹车、悬停和短距离后退。
- 在上下分支、峡谷、洞穴或设施之间选择路线。
- 俯冲快速进入。
- 缓慢滑翔并触发景观/广播信息。
- 使用 Boost 突破重力、风暴或危险窗口。
- 在装有激光炮时轰击指定陨石。

不允许长时间掉头向左飞完整条路线，以保护电影化构图和叙事节奏。

#### M0 路线节奏与控制帮助

- 单颗主线星球的横版进入目标约为 1–3 分钟；快速俯冲倾向 `60–100 s`，
  常规路线倾向 `90–150 s`，缓慢观景倾向 `120–180 s`。玩家主动悬停、
  倒车或停留可以超过三分钟，但关卡不得依赖长段空白飞行拖长流程。
- 该时长是节奏参考，不是失败倒计时。HUD 可显示阶段、进度和经过时间，
  不把主线变成强制竞速。
- 主线以满燃料出发，初始燃料必须覆盖正常路线；M0 不通过中途加油站、拾取
  或补给小游戏修补预算。检查点提供合理的安全燃料下限，零燃料仍保留应急
  普通推力，但不能使用 Boost。
- 首次进入横版飞行会打开可复用“飞行控制”面板并冻结飞行、危险和路线计时；
  玩家确认后开始，飞行中可按 `C` 随时复开。常驻 HUD 只保留紧凑帮助提示，
  完整按键和仅测试模式工具不长期遮挡飞行区域。
- 阶段 1–5 没有可接地表面；阶段 5 后半只根据玩家真实进入轨迹建立后续地表
  的垂直坐标，不能在阶段 6 边界瞬移飞船、清空速度或强制统一进入高度。阶段
  6–8 的可见地形、碰撞、雷达设施与着陆台必须随同一地表坐标进入画面。

#### M0 最后三阶段职责

- **阶段 6：低层沙漠、设施与低空管制雷达。** 原低层沙漠与设施雷达内容
  合并为持续的管制区。雷达与 HUD 共用当地地表高度；当前安全线为
  `高度 ≥ 300 m`。高于安全线不会锁定，持续低于安全线才依次进入警告、
  锁定和一次资源脉冲。M0 不再用贴地或地形遮挡作为安全规则。
- **阶段 7：脱离管制区与着陆准备走廊。** 离开阶段 6 后彻底清理雷达状态，
  玩家获得抬升到约 `400–800 m`、稳定姿态、减速并观察远处着陆信标的时间。
  本阶段不包含扫描或低飞要求。
- **阶段 8：最终着陆进场。** 玩家从较高、可控的位置向平台下降，前段观察
  和对准，中段减速和下降，最后接近才进入平台碰撞范围。它不要求玩家从贴地
  状态重新爬升，也不通过加长平台本体制造进场距离。平台是有限接触区；未完成
  着陆便越过尾缘时明确判定本次进场失败，并返回阶段 8 安全检查点重新对准。

### 2.4 交付动作

交付方式由订单和文明决定：

- 着陆：减速并进入宽容平台/地面区域。
- 空投：在速度、高度和位置窗口内释放货物。
- 检查门：保持特定状态穿过扫描设施。
- 对接：在空间站或大型设施附近完成简化对接。
- 移动目标交接：未来可选。
- 救援乘客：未来可选。

M0 正式实现着陆。M1 至少再实现低空投放；其他方式先保留数据类型。

### 2.5 目的地剧情

**表现：** 场景式对话为主，小型可步行区域为辅。

标准流程：

1. 着陆/交付后显示地点建立镜头。
2. 与收件人进行主要场景对话。
3. 重要地点开放 1–2 屏可步行区域。
4. 玩家可与一名 NPC、一个环境物件和一个可选对话互动。
5. 触发订单结果和返航。

这里不加入战斗，也不发展成完整 RPG 城镇探索。

## 3. 核心循环

### 主线循环

```text
在快递站恢复日常
→ 获得主线问题或订单
→ 查看星球与客户信息
→ 通过主线/支线满足飞船要求
→ 配置唯一飞船
→ 与老皮出发
→ 驾驶舱旅行与剧情
→ 星球进入和地表飞行
→ 完成交付动作
→ 认识角色并作出局部选择
→ 结算、获得模块/许可/线索
→ 回到变化后的快递站
```

### 支线循环

```text
发现支线订单或求助
→ 判断风险、报酬和角色意义
→ 选择是否执行
→ 以较短路线完成配送/探索
→ 根据时间与货物状态获得部分或完整报酬
→ 解锁升级资源、人物内容、图鉴或主线路径替代方案
```

支线允许失败、货损和报酬减少，但不造成飞船维修债务或主线死档。

## 4. 订单系统

### 一次一单

玩家一次只携带一份订单，避免 M0/M1 过早变成路线优化模拟。后期如需要多单系统，必须作为独立设计重新验证。

### 订单信息

接单前显示：

- 货物名称与说明。
- 发件人、收件人。
- 报酬。
- 距离/航程。
- 星球自然环境。
- 风险等级。
- 主线“必须配置”或支线“推荐配置”。
- 客户历史订单。
- 交付方式。
- 是否加急。

重要信息分层展示，避免把所有背景塞进一屏。

### 主线与支线差异

| 项目 | 主线 | 支线 |
|---|---|---|
| 飞船配置 | 可有必须配置，且有确定获取路径 | 主要为推荐配置 |
| 时间限制 | 通常无硬失败时间 | 加急订单可超时减报酬 |
| 撞毁 | 检查点重试 | 可重试或放弃，放弃即失败 |
| 货物完全损坏 | 重试或剧情保底 | 订单可失败 |
| 推进 | 完成后推进主线 | 提供资源、关系、探索和替代路径 |
| 经济风险 | 不阻塞继续游戏 | 只损失本单部分收益 |

## 5. 货物系统

货物首先是剧情对象，然后才是玩法约束。

M0 货物以图标、仪表和文本表示，不模拟真实悬挂物理。后续可通过 Sprite 或货舱展示增强视觉，但不把摆动物理设为必要系统。

货物可影响：

- Boost 是否受限或增加风险。
- 可容忍碰撞次数/强度。
- 是否吸引生物、扫描或其他威胁。
- 所需飞船模块。
- 允许的交付方式。
- 货物完整度下降时的剧情后果。

反馈：

- 百分比完整度。
- 飞行 HUD 与货舱仪表。
- 公司管理层电话/终端警告。
- 老皮的情境台词。
- 结算与 NPC 反应。

不为每次轻微波动打断玩家；警告需要冷却和优先级。

## 6. 飞船与资源

玩家长期使用同一艘飞船。

### 资源条

- **Hull / 船体：** 严重碰撞后的最终承伤层。
- **Shield / 护盾：** 吸收擦碰和环境伤害，可在安全状态恢复。
- **Fuel / 燃料：** 长线推进资源；普通飞行缓慢消耗。
- **Boost Energy / Boost 能量：** 短时高功率资源，可恢复。
- **Cargo Integrity / 货物完整度：** 订单结果核心指标。

M0 不加入热量独立资源条。若大气过热需要表现，先作为危险状态/阈值而非第六条常驻资源。

### 模块

首版模块类别：

- 动力：引擎、Boost、燃料效率。
- 防护：护盾、大气/高压屏蔽。
- 功能：激光炮、扫描、货舱稳定。

主线特殊模块可以通过剧情确定获得。普通数值和可选模块可用信用点购买。

## 7. 武装与和平倾向

M0/M1 的系统表达非常克制：

- 激光炮只轰击陨石和标记为可破坏的环境障碍。
- 不存在敌人生命值、海盗 AI 或地表战斗。
- 某些文明会检查玩家是否安装武器。
- NPC 可能因武装状态改变态度、要求玩家封存武器或提供不同路线。
- 和平路线不应等于“少装一个有趣功能”；应获得不同便利、信任或内容。

未来战斗若加入，必须重新证明不会吞噬配送和叙事核心。

## 8. 经济与进度

### 主要经济

- 一种主要货币：公司信用点。
- 一种或多种非消耗进度：星球关系、通行许可、剧情标记。
- 不设置贷款、利息和强制维修费。
- 船体在返回站点后自动恢复，或通过免费基础维护恢复。

### 主线门槛

允许要求特定模块或许可，但必须提供：

- 确定的主线/支线获取路径。
- 通常不超过 2–3 个有意义订单的资源量。
- 必要时的角色关系或替代模块解法。

不允许随机掉落或漫无目的刷钱决定是否能继续主线。

### 快递站升级

升级优先体现为：

- 新功能：通讯室、扫描台、模块工作台。
- 新角色/访客。
- 新对话或信息源。
- 可见装修：植物、灯光、仓库、纪念品墙。
- 更便利的流程。

不要把站点建设做成独立资源管理模拟。

## 9. 失败、重试与安全网

不可违反原则：

> 玩家永远不能因为连续失败而失去继续推进主线的能力。

规则：

- 主线高速撞毁：最近阶段检查点重试。
- 主线燃料耗尽：应急储备/拖航或重试，允许老皮/公司吐槽，不扣关键进度。
- 主线货物损坏严重：允许重试；也可在特定剧情中以较差结果继续，但不能死档。
- 支线撞毁：重试或放弃。
- 支线货损：报酬减少；完全损坏可判失败。
- 返回站点后船体恢复，不收阻塞式维修费。
- 飞行中随时可一键重开当前段。

检查点按叙事阶段布置，而不是每几秒机械放置。

## 10. 俯冲与缓降

游戏不显示街机分数或连击。系统在后台识别：

- `DIVE`：快速俯冲、最大下降速度高、风险高、较少观景触发。
- `GLIDE`：浅角度进入、时间长、观景/广播触发更多。
- `BALANCED`：介于两者之间。

结果影响：

- 老皮和 NPC 台词。
- 景观/扫描图鉴。
- 少量支线条件。
- 公司风险记录或角色印象。

不影响主线能否继续，也不把其中一种标记为“正确玩法”。

M0 的时长倾向与风格识别相互独立：快速路线通常更容易形成 `DIVE`，缓慢观景
路线通常更容易形成 `GLIDE`，但分类仍由实际下降速度、风险、观景触发和拉起
记录决定，不能只按通关秒数贴标签。

## 11. 辅助与可访问性

M0 至少提供：

### 慢动作辅助

- 危险预警时可自动或手动短暂减速。
- 不影响剧情和报酬。
- 可关闭。

### 路线提示

- 显示下一安全方向、交付区域和关键危险预警。
- 不是自动驾驶。
- 玩家可从飞行控制帮助直接切换；关闭后同时隐藏轨道/入层引导线、低空管制
  航线提示和着陆进场标记，不影响真实碰撞、危险或任务状态。

### 高对比度地形

- 强化碰撞轮廓、危险设施和背景层分离。
- 不只改变色相，兼顾明度和图形符号。
- 玩家可从飞行控制帮助直接切换；赤砂星地表上缘会同时提高亮度和轮廓宽度，
  低空设施与着陆区继续使用同一设置。

### 辅助驾驶

- 0%–100% 可调，默认约 75%。
- 影响重力补偿和姿态稳定，不是难度标签。

此外支持：

- 屏幕震动强度。
- 闪光/雷电强度。
- 字幕与文字速度。
- 音乐/音效/对白提示音量。

## 12. UI 信息层级

飞行 HUD 常驻只显示：

- 速度/关键姿态简化信息。
- 船体、护盾、燃料、Boost、货物完整度。
- 当前目标方向/距离。
- 重要危险状态。

仅在需要时显示：

- 雷达扫描风险。
- 着陆条件。
- 公司警告。
- 辅助提示。

公司货损警告临时占用右上路线卡的既有安全区域，不新增飞行区面板；必须先写
可操作信息，再写制度化黑色幽默，并以文字严重度和符号表达，不能只靠颜色。
底部即时状态仍独立显示雷击、碰撞、雷达或重试反馈，二者不得互相覆盖。

开发调试 HUD 与玩家 HUD 完全分开，可随时关闭。

## 13. 首版内容预算

### M0

- 1 个快递站大厅。
- 1 个驾驶舱。
- 1 颗完整赤砂星。
- 1 份主线订单。
- 老皮 + 1 名星球主要 NPC。
- 1 种正式交付：着陆。
- 1 个武器模块：激光炮，仅打陨石。

### M1

- 4 颗主线星球。
- 每星至少 1 份主线订单、1–2 名核心 NPC、1 个独特进入机制。
- 少量支线订单。
- 着陆 + 空投至少两种交付方式。
- 飞船与站点初步升级循环。
- 有起承转合的 Demo 主线与悬念结尾。

详细边界见 `04_DEMO_SCOPE.md`。
