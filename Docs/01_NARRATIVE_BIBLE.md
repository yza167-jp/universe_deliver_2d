# 01 — Narrative Bible / 叙事圣经

本文件区分已锁定正史、当前工作骨架和开放问题。Codex 不得把候选或暂定内容擅自升级为正史。

## Canon Status

- **LOCKED**：用户已确认，修改需明确新决定。
- **PROVISIONAL**：当前可用于 M1 设计与占位实现，后续可改。
- **OPEN**：尚未决定，只保留接口/候选。
- **CANDIDATE**：提供给用户选择的名称或细节，不等同于已采用。

---

## 1. 已锁定设定（LOCKED）

### 标题与玩家

- 中文：**《我在宇宙送快递》**。
- 英文工作名：**Universe Deliver**。
- 玩家是来自地球的人类。
- 玩家受雇于银河外卖公司，被分配到边境快递站。
- 玩家可以通过少量选项表达态度，但不是大段自说自话的固定主角。
- 玩家默认无配音。

### 老皮

- 老皮是一名外星人，外形是一只水豚。
- 他会直立行走、会说话，拥有职业身份和独立人格。
- 老皮从开场就是固定伙伴，并在站点与副驾驶位置出现。
- 老皮承担前期教程，但不能退化为纯提示器。
- 名字固定为“老皮”。
- 不同文明通过普及的同声传译器交流。

### 游戏结构

- 有明确主线和结局的单人叙事游戏。
- 主线星球按大致固定顺序解锁。
- 可以存在支线、回访和主线后继续游玩。
- 主线尽量不产生大规模分叉。
- 约 95% 图鉴完成度可在完整游戏中触发隐藏结局；M1 不实现该结局。

### 飞船、基地与战斗边界

- 玩家长期使用同一艘飞船，通过数值、模块和剧情功能升级。
- 快递站可以升级并出现可见变化。
- 中后期站点可能迁移、受损或被迫离开，但仍是 OPEN。
- 玩家可以形成和平/武装倾向。
- M0/M1 激光炮只用于陨石和明确可破坏环境物。
- 目的地剧情和地表步行段没有战斗。
- 主线失败不得形成经济死档或强制维修债务。

### 表现结构

- 快递站：2D 俯视可步行空间。
- 星际旅行：2D 第一人称可交互驾驶舱。
- 星球进入/配送：横向侧视、完全可操控。
- 落地后：场景式对话为主，1–2 屏小型可步行区域为辅。
- 交付方式可以包括着陆、低空投放、检查门和对接。

## 2. 世界骨架（PROVISIONAL）

### 银河外卖公司

工作名：**银河外卖公司**。英文法人名未锁定，可继续使用 `Galactic Delivery Corporation` 占位。

公司不是纯恶反派，而是：

- 庞大、官僚、逐利。
- 提供真实必要服务。
- 内部有普通员工、互相冲突的部门和真诚帮助者。
- 对风险有冗长免责条款。
- 依赖远早于自身的物流设施，却在宣传中模糊来源。
- 对边境站点采用成本中心思维。

黑色幽默规则：

1. 先提供具体可操作信息。
2. 再用制度化措辞制造荒谬感。
3. 不在高强度操作时播放长文本。
4. 不让公司成为每颗星球唯一冲突来源。

### 同声传译器

- 常见基础设施，通常自然翻译。
- 可在少量剧情中出现文化语义偏差。
- 不把语言不通作为每星重复障碍。
- 它可能与中继网共享协议，但未锁定。

### 古老中继网 / Relay Lattice

当前骨架：

> 银河外卖公司在一套远早于公司成立的节点网络上经营跨星物流。玩家与老皮通过不同星球的订单逐渐发现，各文明曾把同类节点用于资源、档案、生态周期或天气航路。老皮能感知普通设备无法识别的部分信号，但原因未知。

M1 允许明确揭示：

- 中继网早于公司。
- 赤砂、白噪、穹林和群潮文明都曾接触或利用它。
- 老皮能听见/感知普通终端无法解析的信号。
- 群潮星结尾显示公司星图以外的收件坐标。

M1 不允许锁定：

- 创造者。
- 网络真正运输什么。
- 老皮与网络的确切关系。
- 公司高层知情程度。
- 坐标是否位于银河之外。
- 最终结局。

## 3. M0 已完成故事基线（LOCKED FOR MILESTONE）

- 边境站长期缺员，老皮带玩家完成入职与首单。
- 公司将站点置于运营观察期。
- 第一份货物是深层冷却泵核心。
- 公司档案称其用于采掘生产，实际收件地点靠近居民维修区。
- 玩家从星系外缘进入赤砂星，经历陨石、大气、雷暴、低空管制雷达和高位着陆。
- 赤砂星雷达最终规则：**高度低于最低安全线会被低空管制雷达警告、锁定和惩罚；高位飞行安全。** 不再采用“贴地躲雷达”。
- 玩家在居民维修场认识伊娅。
- 伊娅维护聚居地冷却和净水系统，对公司既依赖又不信任。
- 玩家获得旧中继铭牌并返回站点。
- 老皮对铭牌产生一瞬异常反应。

### 赤砂星既有角色

**伊娅 / Iya**：M0 工作名已进入实现，M1 继续沿用，除非用户以后明确改名。

- 具体目标：让居民设备运行到下一个风季。
- 不把自己描述为英雄。
- 知道订单记录被改写，但不知道原因。
- M1 中参与屏蔽罩改造并展示首单后果。

## 4. M1 主线骨架（WORKING）

推荐顺序：

```text
赤砂首单（已完成）
→ 赤砂回访
→ 白噪星
→ 穹林星
→ 群潮星
→ 快递站中继观测室结尾
```

### 4.1 赤砂星回访

- 冷却/净水设备已经运行，维修场出现可见变化。
- 玩家送达非标准屏蔽材料。
- 伊娅与老皮根据旧中继铭牌结构制作特高压电屏蔽罩。
- 玩家可以选择是否将完整改装记录上传公司。
- 解锁档案终端和白噪星资格。

### 4.2 白噪星

自然：冰原、冰洞、极光、电磁暴雪、较强重力。

文明：以保存和继承记忆为公共基础设施的冰下档案文明。

冲突：谁有权决定记忆被永久保存、删除或公开；公司希望商业化索引访问。

飞行：强重力、低能见度、电磁干扰；需要特高压电屏蔽罩。

主线作用：证明中继节点曾被用于跨世代档案定位。

支线：`side_white_noise_returned_memory`，私人记忆盒的归还与访问选择。

### 4.3 穹林星

自然：巨树、树冠、藤蔓、孢子、飞行生物、较低重力。

文明：强调生态互依、对外来武器保持警惕的树冠文明。

冲突：外部运输需求与生态边界；货物信号会吸引当地生物。

飞行：树洞、垂直通道、移动生物压力；不进入战斗。

主线选择：封存激光进入核心路线，或保留武器走外缘路线；两路回归同一主线节点。

支线：`side_canopy_spore_drop`，首次正式低空投放。

### 4.4 群潮星

自然：海洋、岛屿、潮汐、强风、雨幕与天气塔。

文明：多个相互竞争的岛屿城邦共享天气塔技术。

冲突：谁控制天气和航路；公共安全与权力分配。

飞行：横风、塔影响区、海面航路与有限浮动平台。

局部选择：单一城邦、城邦联盟公开接口、公司临时托管。

支线：`side_tidal_beacon_before_eye`，宽松加急导航信标电池订单。

高潮：中继节点激活，证明网络早于公司；老皮听见异常讯息，站点显示星图外坐标。

## 6. 角色写作规则

### 老皮

- 经验丰富但不是无所不知。
- 说话直接、松弛，偶尔把危险当行业常识。
- 关心玩家但不持续煽情。
- 不靠动物梗存在。
- 很少替玩家解释按键；UI 负责操作信息。
- M1 中逐步承认自己能听见异常信号，但不解释原因。

### 玩家选项

常规 2–3 项，主要表达：

- 真诚/关心。
- 职业/务实。
- 怀疑/讽刺。

选择必须得到至少一行明确回应；只在真正影响后续时写入变量。

### 核心 NPC

每名至少具备：

- 当前具体目标。
- 与当地文明有关的日常细节。
- 对公司/物流的独立立场。
- 与初印象不完全一致的特征。
- 一个回访时可变化的状态。

候选角色详见 `Docs/M1/Characters/M1_CHARACTER_CANDIDATES.md`。
