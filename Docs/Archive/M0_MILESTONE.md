## M1 不得无理由破坏的基线

- Godot `4.7.1-stable`、Compatibility、640×360、16:9、nearest。
- 键盘鼠标优先，业务代码只读取 Input Map action。
- M0 完整流程与旧存档继续可用。
- 飞船使用显式速度积分，基础手感以 Gate B 结论为准。
- 普通飞行伤害先扣护盾，溢出后才伤害船体与货物。
- 主线失败不能造成经济死档。
- 激光炮只作用于明确的环境目标，不引入地表战斗。
- 模态 UI、交互提示和场景输入遵守已验证的优先级规则。
- M0 的赤砂星路线继续作为回归测试与内容模板，而不是被复制粘贴成其他星球。
