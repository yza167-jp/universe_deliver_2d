# M1 Human Checks / Gate E–I

自动测试负责证明流程和状态没有明显工程错误；Human Check 负责判断星球差异、角色、节奏、可读性与继续游玩的愿望。

## 通用规则

- 只有 T-119、T-129、T-159、T-179、T-199 是 M1 强制 Gate。
- 到达 Gate 时任务与阶段进入 `Human Check`，主 Agent停止扩范围。
- 用户未明确通过前，后续依赖任务保持 `Blocked`。
- 返工只修复阻塞与高优先级问题；非阻塞打磨进入后续任务。
- 每个试玩包必须包含 commit、命令、起点、时长、步骤、3–5 个重点和已知限制。

## Gate E / T-119 — M1 基础与白噪资格

### 范围

- v1→v2 存档迁移。
- 多星球解锁、关系、许可、图鉴和站点状态基础。
- 赤砂星回访。
- 特高压电屏蔽罩确定获取。
- 档案终端和白噪星导航资格。

### 建议时长

20–40 分钟，包含一次 v1 继续游戏与一次回访流程。

### 人工问题

1. M0 已完成存档能否自然进入 M1，而不像重开新项目？
2. 赤砂回访是否展示了首单的后果和伊娅的持续存在？
3. 屏蔽罩获取是否像剧情成长，而不是系统发奖？
4. 档案终端和站点变化是否增加“家在成长”的感觉？
5. 白噪星门槛是否清楚、确定且不要求刷取？

### Gate E Round 1 试玩包

主流程使用隔离进度，不读取或写入正常玩家存档：

```bash
export GODOT_BIN="/Applications/Godot.app/Contents/MacOS/Godot"
"$GODOT_BIN" --path . --language zh_CN -- --m1-debug=gate_e
```

起点是 M0 首单完成后的大厅：赤砂星、伊娅、旧中继铭牌和 `100` 信用点已保留，
赤砂回访尚未接取，特高压电屏蔽罩与白噪导航尚未解锁。实际 v1 文件迁移由
测试专用路径自动验证；这个人工入口只提供等价、可重置且不污染玩家主档的体验
起点。

试玩步骤：

1. 查看首单纪念品与大厅状态，再到订单终端接取赤砂回访。
2. 在工作台确认配置，进入驾驶舱并完成旅行。
3. 飞过短服务航道，观察运行中的净水/冷却设施并完成着陆。
4. 在维修场完成伊娅与老皮的主对话，选择上传完整记录或保留本地记录；可查看
   冷却设备与记录终端后返航。
5. 查看结算中的关系、屏蔽罩、档案终端与下一步提示，再返回大厅。
6. 与老皮交谈一次并浏览档案终端，确认赤砂后果、白噪线索和旧铭牌异常边界。
7. 打开订单终端查看白噪风险；在工作台卸下、再装回特高压电屏蔽罩，确认门槛
   从“待安装”变为“资格已满足、航路待开放”。

如需单独检查驾驶舱中的白噪预览，使用：

```bash
"$GODOT_BIN" --path . --language zh_CN -- \
  --m1-debug=white_noise_catalog --show-debug-ui
```

关闭订单预览后，点击顶部调试栏的 `COCKPIT`，再激活 Navigation。这里只应显示
白噪风险、已安装屏蔽罩和“正式航路待开放”；不能接单或开始旅行。

已知限制：

- 白噪星订单、航路与环境仍是 `REGISTERED_ONLY`，本 Gate 不提供白噪飞行。
- `gate_e` 自动存档关闭；`F6` 会重置整个隔离起点，退出进程后不保留试玩进度。
- 新角色与货物显示名仍为 PROVISIONAL；本 Gate 不判断最终美术或英文完成度。

### 通过后

- T-119 Done。
- 阶段 B Done。
- T-120 Ready。

## Gate F / T-129 — 白噪星完整订单

### 范围

- 白噪星驾驶舱旅行、完整路线、强重力、电磁暴雪、屏蔽差异。
- 记忆档案文明、核心 NPC 和局部选择。
- 白噪星支线。
- 结算、关系、许可、图鉴与返站。

### 建议时长

35–60 分钟。

### 人工问题

1. 白噪星是否在前几分钟内就与赤砂明显不同？
2. 较强重力和电磁干扰是否有压力但仍可理解？
3. 屏蔽罩是否改变玩法，而不只是资格钥匙？
4. 记忆冲突是否通过人物成立，而非百科说明？
5. “被退回的记忆盒”是否像可选人物故事，而不是必清任务？

### 通过后

- T-129 Done。
- 阶段 C Done。
- T-140 与后续中段任务按依赖解锁。

## Gate G / T-159 — 穹林星与低空投放

### 范围

- 树冠路线、较低重力、孢子与生态压力。
- 激光炮封存/保留选择。
- 生物信号隔离舱。
- 穹林主线与“孢子季急投”支线。
- 低空投放。
- 生态角和关系反馈。

### 建议时长

40–70 分钟，至少分别试一次封存与保留武器的关键段。

### 人工问题

1. 武装选择是否有实际影响但不显得惩罚玩家？
2. 飞行生物是否像生态压力而非敌人？
3. 树洞/树冠路线是否清楚且不造成碰撞挫败？
4. 低空投放的高度、速度和位置窗口是否容易理解？
5. 穹林文明、角色和站点生态角是否形成温暖余韵？

### 通过后

- T-159 Done。
- 阶段 E Done。
- T-170 Ready。

## Gate H / T-179 — 群潮星与 Demo 高潮

### 范围

- 群潮星完整路线、横风、天气塔和浮动平台。
- 横风稳定器。
- 主线天气控制货物与三个局部选择。
- “风眼前的灯”加急支线。
- 中继网第一层揭示和中继观测室。

### 建议时长

45–75 分钟。

### 人工问题

1. 横风是否明显且可预判，稳定器是否有意义但不自动驾驶？
2. 群潮星是否具有高潮感，而不是普通第四关？
3. 控制权选择是否有可信反馈，即使不分裂主线？
4. 加急支线是否增加节奏而不是焦虑劳动？
5. 中继网揭示是否足够清楚又保留神秘？

### 通过后

- T-179 Done。
- 阶段 F Done。
- T-190 Ready。

## Gate I / T-199 — Four-Planet Demo 最终验收

### 范围

从新游戏或 M0 v1 档开始，完整经历：

```text
赤砂首单
→ 赤砂回访
→ 白噪主线与支线
→ 穹林主线与低空投放支线
→ 群潮主线与加急支线
→ 中继观测室结尾
→ 退出与继续游戏
```

赤砂 Stretch 支线如果已经完成则纳入；若 Deferred 不影响 Gate。

### 建议时长

2–4 小时，可分段试玩，但最终至少完成一次连续章节状态验证。

### 最终问题

1. 四颗星球是否像不同地点、文明与旅途记忆？
2. 老皮和核心 NPC 是否让玩家愿意继续了解？
3. 主线、支线、回访、模块和站点成长是否彼此连接？
4. 飞行与交付机制是否有变化，但仍像同一款游戏？
5. 失败、重试、资源和主线门槛是否公平？
6. 2–4 小时内容是否密度合理，没有刷取和空白拖时？
7. 群潮高潮和星图外坐标是否构成有效 Demo 结尾？
8. macOS 构建、Windows 启动验证、存档、继续、可访问性和性能是否可接受？

### 完成后

- M1 所有必做阶段 Done。
- T-141 可 Done 或 Deferred。
- 创建 M1 里程碑提交/标签。
- 更新 README 与发布说明。
- 未经新的 M2 规划，不直接扩展完整游戏范围。
