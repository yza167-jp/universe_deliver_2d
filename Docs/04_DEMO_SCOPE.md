主菜单

## 3. M1 — Four-Planet Demo

### 3.1 Demo 目标

M1 要证明游戏不只是赤砂星的一次性概念，而是能够让不同自然环境、文明、角色、货物和飞行机制组成连续主线。

Demo 应具有：

- 明确序章、发展、高潮和悬念结尾。
- 四颗可进入主线星球。
- 至少一次明显回访。
- 初步飞船升级和快递站变化。
- 三份必做支线，展示自由探索而非刷取。
- 着陆与低空投放两种正式交付。
- 古老中继网的第一层明确揭示。
- M0 v1 存档安全迁移。

### 3.2 推荐主线顺序

```text
赤砂星首单（M0）
→ 赤砂星短回访与特高压电屏蔽罩
→ 白噪星
→ 穹林星
→ 群潮星
→ 中继观测室 Demo 结尾
```

### 3.3 主线预算

| 主线订单 | 内容 |
|---|---|
| 1 | 赤砂星首单，M0 已完成 |
| 2 | 赤砂星回访与屏蔽罩改造 |
| 3 | 白噪星记忆档案订单 |
| 4 | 穹林星生态货物订单 |
| 5 | 群潮星天气塔控制订单 |

### 3.4 支线预算

必做：

1. 白噪星“被退回的记忆盒”。
2. 穹林星“孢子季急投”。
3. 群潮星“风眼前的灯”。

Stretch：

4. 赤砂星“配额之外的滤芯”。

支线规则：

- 每次仍只接一单。
- 可失败、减报酬或放弃。
- 不造成主线死档。
- 不随机刷新，不提供无限刷钱。
- 优先复用路线分支、目的地区域和已有系统。

### 3.5 四星差异矩阵

| 星球 | 自然 | 人文 | 独特飞行 | 叙事问题 | 模块/配置 |
|---|---|---|---|---|---|
| 赤砂 | 沙漠峡谷、尘暴 | 采掘殖民地与居民维修场 | 低空管制雷达、高位着陆 | 生存资源与公司配额 | 取得特高压屏蔽罩 |
| 白噪 | 冰原、冰洞、电磁暴雪、强重力 | 记忆档案文明 | 低能见度、电磁干扰、提前拉起 | 谁决定记忆被保存/公开 | 特高压电屏蔽罩必需 |
| 穹林 | 巨树、孢子、飞行生物、低重力 | 树冠生态文明 | 树洞、垂直通道、生态吸引 | 运输需求与生态边界 | 隔离舱推荐；武器封存选择 |
| 群潮 | 海洋、岛屿、潮汐、横风 | 城邦与天气塔 | 风场、海面航路、浮动平台 | 谁控制天气与航路 | 横风稳定器推荐 |

### 3.6 每颗新增星球最低包

- 1 份 Planet Packet。
- 1 条完整进入/配送路线。
- 1 份主线订单。
- 1 件专属剧情货物。
- 1 个独特环境/文明机制。
- 1–2 名核心 NPC。
- 1 个小型目的地区域或高质量场景交付。
- 1 个纪念品/图鉴条目组。
- 1 个未来回访种子。
- 独立色板、背景、VFX、环境音和主题动机。

### 3.7 M1 新增系统

允许：

- Save schema v2。
- 多星球解锁、章节、关系、许可、图鉴和回访。
- 主线/支线订单状态，仍一次一单。
- 加急支线与超时减报酬。
- 低空投放。
- 更完整但受控的飞船模块与站点变化。
- 武装/和平倾向反馈。
- 局部选择与 Demo 结尾变量。

不允许：

- 完整敌人战斗。
- 多飞船购买。
- 程序生成路线。
- 多单同时配送。
- 复杂贸易。
- 大型基地经营。
- Steam SDK、云存档和成就。

### 3.8 时长

- 首次主线目标：约 2–4 小时。
- 支线/回访：额外约 30–75 分钟。
- 单颗主线飞行进入：约 1–3 分钟。

时长是范围估计，不通过空白飞行、重复刷单或长篇百科凑数。

### 3.9 美术标准

M1 目标是 production placeholder：

- 风格统一、可分享、可用于截图。
- 不是最终商业美术。
- 生成式候选必须修整像素密度、轮廓和伪文字，并记录来源。
- 每颗星球必须拥有独立色板、关键景观、环境 VFX 和音频动机。

### 3.10 Human Check

- Gate E：M1 共用系统、迁移、赤砂回访与白噪资格。
- Gate F：白噪完整订单。
- Gate G：穹林、武装选择与低空投放。
- Gate H：群潮与高潮。
- Gate I：完整 Four-Planet Demo。

每个 Gate 未通过前，不扩展下一大内容层。

## 4. M1 完成门槛

详见 `CODEX_GOAL.md` 与 T-199。至少满足：

- 四颗星球主线可连续完成。
- 三份必做支线可完成/失败并保存。
- v1→v2 迁移可靠。
- 两种正式交付可用。
- 三件剧情模块与三次站点变化成立。
- M0 回归通过。
- Gate E–I 通过。
- macOS 可分享构建和 Windows 启动验证完成。

## 5. M2+ 远期方向

只保留愿景，不进入当前任务：

- 更多主/支线星球。
- 主线结局与约 95% 图鉴隐藏结局。
- 主线后持续订单和宇宙秘密探索。
- 可能的站点迁移/受损剧情。
- 可选海盗追逐或护航，但不得吞噬叙事核心。
- 更深入的飞船与站点长期成长。
- 多平台正式发行。

## 6. 范围变更规则

任何新增功能先判断：

- M1 必要。
- M1 打磨。
- Stretch。
- M2+。

新增 M1 必做任务时必须同时说明：

- 它解决哪个 Gate 的阻塞。
- 是否替代/缩小现有内容。
- 为什么不能用更小、可逆方式验证。

不能只增加范围。
