# 12 — M1 Iteration Gates / M1 人工试玩门

自动检查负责证明工程和状态合同成立；人工试玩负责判断星球、角色、节奏、手感和继续游玩的愿望。M1 只在以下五个综合节点强制暂停。

## 通用规则

到达 Gate 时主 Agent 必须：

- 将对应任务与阶段标记为 `Human Check`。
- 停止领取新任务。
- 提供精确运行命令、起点、预计时长、重试方式和已知限制。
- 列出 3–7 个需要玩家判断的问题。
- 自动检查通过后可以提交实现，但不能自行把 Gate 改成 `Done`。
- 玩家反馈中的阻塞问题在当前 Gate 返工；非阻塞打磨记录为后续任务。

每个 Gate 通过后：

- 记录结论到任务与 Decision Log。
- 将 Gate 任务和所属阶段改为 `Done`。
- 只解锁直接下一阶段，不自动开始实现。

## Gate E — 白噪星垂直切片

**任务：T-119**  
**预计试玩：20–40 分钟**

### 路径

```text
M0 完成档或迁移 fixture
→ 白噪星订单与屏蔽罩获取
→ 驾驶舱航程
→ 白噪星完整路线
→ 冰下档案区剧情
→ 结算与返站
```

### 必须判断

1. 白噪星是否在重力、能见度、环境危险、建筑、角色和声音上明显不同于赤砂星？
2. 特高压电屏蔽罩的获取和配置门槛是否自然，而不是人为拖延？
3. 电磁干扰是否可读、公平，并且没有隐藏主线必需信息？
4. 记忆档案文明和核心 NPC 是否像具体地点与人物？
5. 完成第二颗星球后是否想继续回访赤砂并推进主线？
6. M0 赤砂流程是否没有回归？

### 通过条件

- 新增星球不是换皮。
- 屏蔽罩与独特危险成立。
- 完整订单流程、迁移和保存稳定。
- 只有有限、明确的打磨项。

## Gate F — 成长、支线、低空投放与赤砂回访

**任务：T-129**  
**预计试玩：30–60 分钟**

### 路径

```text
白噪星完成后返站
→ 查看站点变化与图鉴
→ 完成一份支线加急订单
→ 完成一份低空投放订单
→ 购买/获得一次升级或许可
→ 回访赤砂星与伊娅
→ 返回站点并保存
```

### 必须判断

1. 赤砂星回访是否真正展示了首单造成的变化？
2. 支线是否提供角色、探索或替代路径，而不是重复刷信用点？
3. 低空投放是否与着陆明显不同，判定清楚且可快速重试？
4. 信用点、模块、关系、许可、图鉴和纪念品是否形成可理解的成长？
5. 主线门槛是否不存在随机或刷取压力？
6. 快递站是否逐渐像一个变化中的家？

### 通过条件

- 至少一次回访成立。
- 至少一份支线和一份投放订单成立。
- 成长系统增加意义而非菜单负担。
- 中段存档稳定。

## Gate G — 穹林星自然、文明与武装态度

**任务：T-139**  
**预计试玩：20–40 分钟**

### 路径

```text
接取穹林星订单
→ 分别检查武装与和平配置反馈
→ 驾驶舱航程
→ 树冠路线与生物压力
→ 到达树冠聚落
→ 结算、关系与返站
```

### 必须判断

1. 巨树、树洞、藤蔓和树冠通道是否形成独特空间记忆？
2. 飞行生物是否像生态压力而不是缺少血条的敌人？
3. 剧情货物为何吸引生物是否讲得通？
4. 激光炮安装与否是否带来真实的信任、通行或内容差异？
5. 和平配置是否获得正向内容，而非单纯少一个工具？
6. 核心 NPC 与生态文明是否成立？

### 通过条件

- 穹林星不是白噪/赤砂换皮。
- 非战斗生态机制成立。
- 武装/和平倾向有实际反馈且不分裂主线。

## Gate H — 群潮星高潮与中继网揭示

**任务：T-149**  
**预计试玩：25–45 分钟**

### 路径

```text
接取群潮高潮订单
→ 驾驶舱中接收多星球信息
→ 海洋、横风、潮汐、移动平台与天气塔路线
→ 城邦到达剧情
→ 中继网证据交汇
→ 结算与 Demo 后状态
```

### 必须判断

1. 横风、潮汐、移动平台和天气塔是否清楚、公平且不互相堆叠过量？
2. 群潮星是否有独立文明与视听身份？
3. 前三星的线索与人物立场是否自然交汇？
4. 中继网“不是公司建造”是否被明确建立？
5. 是否仍保留创造者、用途和老皮关系的神秘？
6. Demo 结尾是否产生继续完整游戏的愿望？

### 通过条件

- 群潮星形成真正高潮。
- 中继网揭示清楚但不过度解释。
- Demo 后仍可继续支线、回访和保存。

## Gate I — M1 Four-Planet Demo 完整闭环

**任务：T-159**  
**预计试玩：2–4 小时，可分两次完成**

### 测试档

至少测试：

- 新游戏档。
- M0 schema v1 迁移档。
- 一份中途 M1 存档。

### 完整路径

```text
序章/赤砂首单状态
→ 白噪星
→ 赤砂回访、支线和投放
→ 穹林星
→ 群潮星高潮
→ Demo 结尾
→ 继续游戏、图鉴与站点
```

### 最终判断

1. 四颗星球是否在自然、人文、飞行、角色和声音上都能被记住？
2. 老皮、驾驶舱和快递站是否持续提供陪伴与余韵？
3. 主线是否具有序章、发展、中场、高潮和悬念结尾？
4. 支线、回访、升级、关系、许可和图鉴是否增强世界，而非制造重复劳动？
5. 着陆和低空投放是否各自成立？
6. 失败、重试、迁移、保存和继续游戏是否公平可靠？
7. 玩家是否愿意把 Demo 推荐给外部玩家？
8. 玩家是否想继续追查老皮与中继网？

### 完成条件

- 玩家明确接受 M1，或只留下有限可关闭的阻塞项。
- 修复后自动检查和关键路径回归通过。
- 创建 M1 里程碑提交或标签。
- 才允许建立 M2+ 活动任务。

## 非强制检查

单个 UI、数据、对白或灰盒任务不应默认进入 Human Check。只有存在会阻塞后续阶段的关键主观风险时，才额外请求短试玩，并说明为何不能集中到下一 Gate 判断。
