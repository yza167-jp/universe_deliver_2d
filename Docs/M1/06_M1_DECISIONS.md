## 变更规则

- 新用户决定优先于本文旧决定。
- 修改 Locked 项时新增新行，并将旧行标记为 Superseded；不删除历史。
- Working 项可由 Gate 调整，但必须记录原因和影响任务。
- Open 项不得由 Agent 根据个人偏好静默关闭。
