# M1 Four-Planet Demo — 规划决定

本文件只记录 M1 规划产生的增量决定。全项目长期决定仍以 `Docs/08_DECISION_LOG.md` 为准；若本文件与后续用户明确决定冲突，以后者为准，并在主 Decision Log 中追加替代记录。

## 状态

- `Locked`：已经由既有产品决定或 M0 验收锁定。
- `Working`：M1 当前默认方案，可在对应 Gate 通过前调整。
- `Open`：尚未决定，不得由 Agent 静默锁定。

## 变更规则

- 新的用户明确决定优先于本文件。
- 改变 Working 项时说明影响的任务、数据、剧情和测试。
- Open 项只能由用户决定，或由任务产生一个明确待确认方案。
- 不删除旧决定；被替代时保留并标记 `Superseded`。
