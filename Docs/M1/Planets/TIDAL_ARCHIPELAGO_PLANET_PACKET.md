# Planet Packet — Tidal Archipelago / 群潮星

## Canon status

- 海洋、岛屿、强风、雷暴、潮汐、城邦和天气塔：PROVISIONAL 框架已批准用于 M1。
- 角色显示名、物种、货物名和城邦名：候选制。

## One-sentence identity

一颗由岛屿城邦和天气塔网络维持航路的海洋星球，公共安全、贸易与政治权力都被同一套气象控制系统绑在一起。

## Narrative role

- M1 第四颗完整星球与高潮。
- 验证横风、天气塔和有限移动平台。
- 汇合赤砂、白噪、穹林的中继线索。
- 记录一个局部控制权选择。
- 明确中继网早于公司，并在结尾显示星图外坐标。

## Natural environment

- 相对重力工作范围：0.9–1.05。
- 海洋、岛屿群、风墙、雨幕、潮汐和远处雷暴。
- 海面与岛屿高度提供清晰参照。
- 天气塔改变局部风向、能见度和航道。

## Civilization

- 多个城邦共享天气塔基础技术，但制度、标志与建筑轮廓不同。
- 公共安全依赖塔网；控制权也可用于封锁航路、分配水汽和影响贸易。
- 普通维护者承担塔网持续运行，而政治角色争夺控制接口。
- 公司以跨城邦物流和“临时托管”名义介入。

候选城邦/联盟称呼：

1. **推荐工作候选：** 群潮航路同盟 / Tidal Route Compact
2. 风塔联议会 / Weather-Tower Assembly
3. 岛链公约 / Archipelago Accord

## Local conflict

天气塔控制核心需要更换。不同城邦、联盟和公司都能提供某种稳定方案，但每种方案都改变谁拥有优先航路、维修权限和数据访问。

## Flight identity

阶段建议：

```text
海洋天体与云墙接近
→ 高空横风航道
→ 暴雨/雷暴边缘
→ 岛屿间风道
→ 海面低空或岛脊高线选择
→ 天气塔影响区
→ 浮动维护平台
→ 目的地天气塔
```

独特机制：

- 持续横风与阵风预警。
- 风向/强度在 HUD、粒子、云和海面中可读。
- 横风稳定器降低扰动，不自动修正路线。
- 天气塔区可以改变风场和安全航道。
- 最终平台只做有限、缓慢浮动，不使用复杂刚体船。

## Main order

Stable ID：`order_m1_tidal_weather_core`

候选订单标题：

1. **推荐：**《把风交给谁》
2. 《天气塔临时托管件》
3. 《风暴航路仲裁核心》

候选主线货物：

1. **推荐：** 天气塔共识钥
2. 潮汐控制分配器
3. 风暴航路仲裁核心

Stable cargo ID：`cargo_tidal_weather_control_core`

公司描述：恢复跨城邦天气服务的标准控制组件。

实际意义：组件的授权模式会决定谁能控制塔网、查看航路数据和分配天气窗口。

## Required/recommended loadout

- 推荐：`module_crosswind_stabilizer`。
- 必须模块不应造成临时刷取；稳定器在主线确定路径中获得。
- 屏蔽罩对雷暴/塔网干扰可有轻量帮助，但不替代稳定器。

## Delivery method

- 主线：有限浮动平台着陆或简化对接。
- 复用着陆核心合同；平台运动幅度小、可预测。

## Characters

核心角色 stable IDs：

- `character_tidal_weather_keeper`：天气塔维护者，关注公共运行与维修现实。
- `character_tidal_city_representative`：城邦/联盟代表，表达控制权立场。

公司代表可通过终端出现，不必新增第三名现场角色。

候选显示名见角色文档。

## Arrival scene

- 天气塔维护平台与控制室 1–2 屏。
- 主要角色对控制权、公共安全和公司托管提出不同方案。
- 玩家选择：单一城邦、联盟公开接口、公司临时托管。
- 所有选择进入同一中继节点激活流程。

## Side order

`side_tidal_beacon_before_eye`：风眼前的灯。

- 将导航信标电池送给天气维护队。
- 使用宽松目标时间；超时减信用点/关系，不硬失败。
- 复用群潮路线分支与横风机制。

## Relay clue and climax

- 天气塔底层协议与前三颗星球记录匹配。
- 节点重连后证明网络早于公司。
- 普通终端无法解析一段信号，老皮能听见类似地址确认的残片。
- 快递站中继观测室随后显示公司星图以外坐标。

## Revisit seed

- 天气塔控制权选择改变开放岛屿、航路和角色关系。
- 深海出现新的异常信号。
- 不在 M1 实现完整回访。

## Art package

- 深海蓝、青绿、暴风灰、天气塔金色/红色信标。
- 云墙、岛屿剪影、海面反光、雨幕、塔和平台。
- 不同城邦建筑共享技术基础但轮廓/标志不同。
- 核心 NPC、货物、稳定器和纪念品。

## Audio package

- 海浪、风、雨、塔机械、远雷与平台结构声。
- 安全/横风/天气塔/高潮四层动态音景。
- 主题动机回收前三星中继音型，形成 M1 高潮。
