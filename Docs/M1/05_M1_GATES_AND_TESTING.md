# M1 Four-Planet Demo — Gate 与测试策略

## 原则

自动测试负责状态、数据、迁移、场景和公式；人工试玩负责星球差异、角色、节奏、可读性与继续游玩的愿望。普通任务默认在自动检查和最短烟雾通过后标记 `Done`，强制 Gate 才进入 `Human Check`。

## 强制 Gate

### Gate E — 白噪星垂直切片

确认：

- 白噪星不是赤砂星换皮。
- 较强重力、低能见度与电磁暴雪可读、可控。
- 特高压电屏蔽罩门槛自然且无需刷取。
- 记忆档案文明、NPC、货物和路线互相解释。
- M0 完整流程没有回归。

Gate E 未通过前，不批量制作穹林与群潮的高成本路线。

### Gate F — 回访、支线与成长

确认：

- 赤砂回访展示真实变化。
- 低空投放清楚、宽容且有独特价值。
- 支线和加急订单不是刷取劳动。
- 飞船、站点、图鉴和许可形成可理解成长。

### Gate G — 穹林星与和平/武装反馈

确认：

- 树冠路线和生态压力形成独特记忆。
- 飞行生物是环境压力而非传统敌人。
- 武器状态产生公平的信任、通行或对白差异。
- 分支最终回到同一主线，不发生规模膨胀。

### Gate H — 跨星球成长整合

确认：

- 关系、许可、模块、图鉴、站点变化和支线形成一个清楚循环。
- 多星球导航、回访与存档稳定。
- 玩家知道下一步为何解锁。

### Gate I — 群潮星与高潮

确认：

- 海洋、横风、天气塔和移动平台构成独特路线。
- 群潮星回收前面角色、模块、许可和线索。
- 中继网揭示清楚但没有提前解决终极秘密。

### Gate J — M1 完整 Demo

完整试玩 2–4 小时：

- 完成四星主线。
- 至少完成一份支线、一次低空投放和一次回访。
- 测试失败/重试、退出/继续和 v1 存档迁移。
- 判断四星差异、角色记忆、成长、节奏和结尾悬念。

Gate J 通过后才允许将 M1 标记 `Done`。

## 每个任务的默认验证

除纯文档任务外运行：

```bash
./scripts/check_project.sh
git diff --check
git status --short
```

并执行：

- 当前任务专项测试。
- 受影响场景实例化。
- 最短可玩烟雾。
- 若触及全局状态、存档、导航、对话或飞行，运行 M0 完整闭环回归。

## M1-A 基础测试

### 存档

- v1 正常档迁移到 v2。
- 信用点、订单、模块、纪念物和设置不丢失。
- 完成 M0 首单的旧档解锁白噪星。
- 主档损坏仍可使用备份。
- 高版本或非法状态被拒绝并保留原文件。

### 多星球状态

- 主线章节只允许合法转换。
- 未解锁星球不可确认出发。
- 订单目标与导航目的地一致。
- 关系、许可、回访、图鉴和模块 ID 引用有效。
- 主线与支线状态互不覆盖。

### 路线模板

- 抽取后赤砂星仍可完整运行。
- 白噪星空白路线可实例化。
- 星球专属危险不会泄漏到其他路线。
- HUD、帮助、资源和检查点继续复用既有组件。

## 新星球通用测试包

每颗新增星球至少覆盖：

- PlanetDefinition 与数据引用。
- 主线订单状态流。
- 必需模块/许可门控。
- 驾驶舱旅行与场景交接。
- 路线阶段与检查点。
- 独特危险纯逻辑。
- 交付成功、失败和重试。
- 到达对白条件。
- 结算、解锁、纪念品与返站。
- 保存、退出与继续。
- 640×360 中文可见烟雾。

## 白噪星专项

- 相对重力配置只影响白噪星。
- 未安装屏蔽罩时主线出发被拒绝并显示原因。
- 屏蔽罩有确定获取路径。
- 电磁暴雪不随机禁用输入。
- 干扰不隐藏速度、高度、危险和交付条件。
- 冰洞碰撞与可见几何一致。

## 支线与低空投放专项

- 一次仍只携带一单。
- 加急计时排除暂停、阻塞对话与加载。
- 超时只减少报酬。
- 低空投放读取统一速度、高度和位置窗口。
- 同一次释放只结算一次。
- 偏差产生有限结果并允许快速重试。

## 穹林专项

- 武器状态只影响已定义的态度、通行和对白。
- 飞行生物不进入敌人生命值或战斗系统。
- 货物吸引标签来自 CargoDefinition。
- 树洞和垂直通道在高对比模式下可读。

## 群潮专项

- 横风与天气塔参数数据化。
- 海面、岛屿和移动平台碰撞清楚。
- 移动平台检查点与重试稳定。
- Demo 高潮变量只写入一次。

## M0 回归保护

以下系统变更必须运行完整 M0 流程：

- GameState、SaveService、schema。
- 订单与导航。
- 通用对话与模态 UI。
- 飞船、伤害、资源和检查点。
- 路线模板和环境控制器。
- 结算、站点和纪念品。

回归路径：

```text
新游戏 → 教程/接单/配置 → 驾驶舱 → 赤砂星失败与重试
→ 着陆/维修场/结算/返站 → 保存 → 重建 App → 继续游戏
```

## Gate 试玩包

主 Agent 提供：

```markdown
## Gate / Commit
## How to run
## Start path
## Expected play time
## What changed
## Focus questions
## Known limitations
## Reset / retry
## Regression already checked
```

用户自然语言反馈由主 Agent 整理到任务与决策文档，不建立庞大证据录入系统。

## Gate 失败处理

- 阻塞问题：当前 Gate 任务退回 `In Progress`，只修复明确反馈。
- 非阻塞打磨：记录后续任务。
- 新产品想法：先写 Scope/Decision，不顺手实现。
- 已通过的 M0 基线不因无关 M1 任务重新打开。
